Projects

Vehicle Speed Detection System

Detects vehicles in video, gives each one an ID and estimates its speed to flag over-speeding.

  • Python
  • YOLOv8
  • SORT
  • OpenCV
View code on GitHub
  1. YOLOv8 identifies vehicles in each video frame.
  2. SORT tracking assigns unique IDs so each vehicle is followed across frames.
  3. Pixel-to-meter calibration and distance-time calculations give the speed.
  4. OpenCV handles video processing and the over-speeding logic.

Road Curve Lane Detection

Finds lane boundaries in road video using classical computer vision, for driver-assistance use.

  • Python
  • OpenCV
  • Canny edge
  • Hough Transform
View code on GitHub
  1. Convert frames to grayscale and apply Gaussian blur.
  2. Detect edges with the Canny algorithm.
  3. Mask the region of interest to keep only the road ahead.
  4. Use the Hough Transform to identify lane boundaries.
